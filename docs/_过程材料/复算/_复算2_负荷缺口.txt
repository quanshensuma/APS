  --------------------------------------------------------------------------------

  铣工序：阀体A 写「铣（CNC-03）」点名（该机停机）
         法兰D/端盖E 写「铣（CNC）」组（CNC-01/02/03 任选）

         铣负荷拆解：阀体A 7200 min（点名 CNC-03，停机）+ 其余 8600 min（组）
          情形 R1 阀体A 可走 CNC-01/02 → 铣共 15800 min，容量 11520 → 缺 4280
          情形 R2 阀体A 不能走       → 阀体A 3 单全拦，铣 8600 min，容量 11520 → 缺 0

         磨负荷拆解：阀体A 3000 + 阀体B 2350 + 阀芯C 7000 = 12350 min
          情形 M1 GRD-01 单台（严格点名）  → 容量 5760 → 缺 6590
          情形 M2 允许同组替代(GRD-02启用) → 容量 11520 → 缺 830

D. C3 流水约束（阀芯C 车→磨 ≤30min）的产能代价
======================================================================================
  阀芯C 确定量 = 200 件（103 的 120 + 104 的 80；110 待定）
  车 40 min/件、磨 35 min/件

  口径①：件级严格连续（第 i 件车完工 → 第 i 件磨开工 ≤30）
